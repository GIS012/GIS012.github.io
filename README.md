## 🚀 Overview

This repository contains the production-ready source code for the personal portfolio website of **Rab Nawaz**. Built with semantic HTML5, modern vanilla CSS3 (glassmorphism & responsive grid), and vanilla JavaScript featuring an interactive IT network packet & binary stream canvas engine.

### 🌟 Key Highlights
- **Interactive IT Cyber Stream Engine:** Emits real-time binary bits, network packets (`[ACK]`, `[SYN]`, `[IP]`, `[VLAN]`, `[M365]`), and electric fiber-optic tracer lines tracking cursor movement.
- **Structured Skills Matrix:** Styled following the Tomasz Gajda architecture with `USING NOW`, `LEARNING & ADVANCING`, and `OTHER TOOLS & INFRASTRUCTURE`.
- **Filterable Deployments / Projects:** Instant category filtering across MDM, Cloud & M365, Cisco Networking, EdTech LMS, and Security.
- **3D Page Transitions & Modern Wave Dividers:** Layered SVG wave transitions between sections with smooth 3D scroll reveal animations.
- **Direct Connect:** Single primary CV download button and direct WhatsApp / Email routing.

## 🌐 Deployment to GitHub Pages & Custom Domain (Name.com)

### 1. Enable GitHub Pages
1. Go to your repository **Settings** on GitHub: `https://github.com/GIS012/<repo-name>/settings/pages`
2. Under **Build and deployment > Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.

### 2. Connect Custom Domain from Name.com
1. In repository **Settings > Pages > Custom domain**, type your domain name (e.g. `rabnawaz.com` or `it.yourdomain.com`).
2. GitHub will create a `CNAME` file in your repository.
3. In your **Name.com** account:
   - Navigate to **My Domains > Manage DNS Records**.
   - For an **Apex Domain** (`yourdomain.com`), add 4 `A` records pointing to GitHub Pages IP addresses:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - For a **Subdomain** (`www` or `it`), add a `CNAME` record:
     - Host: `www` (or your subdomain)
     - Answer / Target: `GIS012.github.io`
4. Check **Enforce HTTPS** in GitHub Pages settings once DNS resolves.
